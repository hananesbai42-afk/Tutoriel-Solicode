# Commandes PHP – Environnement local

## 1. Vérifier la version de PHP

Commande exécutée :

```bash
php -v
```

Résultat : PHP 8.5.12 installé avec succès.

## 2. Démarrer le serveur local

Commande exécutée :

```bash
php -S localhost:8000
```

Cette commande permet de démarrer le serveur Web local PHP sur le port 8000.

## 3. Accéder au serveur local

URL utilisée :

```text
http://localhost:8000/test-serveur.php
```

## 4. Arrêter le serveur

Commande clavier :

```text
Ctrl + C
```
